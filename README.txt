NOVA WEB STUDIO — KIT INICIAL

Contenido:
- index.html: estructura y contenido de la página.
- styles.css: diseño visual, responsive, 3D, animaciones y efectos.
- script.js: pantalla de carga, menú móvil, revelado al hacer scroll, efecto de cursor e inclinación 3D.
- assets/: logotipo y tres imágenes SVG de muestra.

Cómo verlo:
1. Descomprime el archivo.
2. Abre index.html en tu navegador.
3. Para editar textos, precios y enlaces, abre index.html.
4. Para cambiar colores, efectos y tamaños, abre styles.css.
5. Para agregar funciones interactivas, edita script.js.

Pendiente de personalización:
- WhatsApp y número telefónico.
- TikTok, Facebook e Instagram.
- Correo real.
- Imágenes o proyectos reales.
- Precios definitivos.

Nota: las imágenes incluidas son gráficos SVG creados para esta maqueta; se pueden reemplazar por capturas o fotos de tus trabajos.
